This code aimed to compute the data of neutron stars in General Relativity, Entangled Relativity and in Entangled Relativity with a retroaction of the scalar field. Also, in it we check that the retroaction of the variation of hbar onto the equation of state of the star has almost no impact.

To launch the codes, after having donwolad everything that is in the folder"New_integrator_shooting_macro_upgrade". After you need to install the packages present in the file requirements.txt.

The, in a terminal you write :

" python3 Get_all_figures.py " 

This line will launch the code. It will lead to the production of a folder named ' save_hbar_NS'. In this one you will find matrices that contains 1000 neutron star's data that ranges from 100 to 2000 MeV/fm3. You will also find 3 plots. Two showing the values of the stars mass versus their radius depending on their relative variation in hbar. These are for the center of the star (scatter_1000.png) and at their surface (scatter_treshold_1000.png). There is also a figure named "hbar_variation_comparison_NS.png", which shows the variation of hbar versus the distance to the star in the case with the retroaction and without.

The code work with previous data ( contained in the matrices ). If you want to run it by yourself download and launch the other folder name ''.

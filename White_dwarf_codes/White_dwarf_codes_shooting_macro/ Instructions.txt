This code aimed to study the variation of hbar predicted by the theory of the Entangled relativity regarding the value of the core density.

To launch the codes, you first need to install the packages present in the file requirements.txt.

After you write in a terminal : 

" python3 Get_all_figures.py " 

This line will launch the code. It will lead to the production of six different things.

- four folders : one contains the stored data of the predicted values of hbar ("hbar_folder"), another contain the stored data of the radius of the star ("radius_folder") another contains the core density values ("init_density_folder"), another one contains the data of hbar at the radius of the star and the last one the value of the radius of the stars. These contain the values for 250 different white dwarf simulation.

- A figure named "deltahbar_vs_radius_WD.png", which shows the variation of hbar versus the distance to the star regarding the core density values. It is figure 6 in the paper.
